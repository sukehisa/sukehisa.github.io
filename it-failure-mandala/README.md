# 【ITプロジェクト版】失敗原因マンダラ図 アセット

失敗したITプロジェクトの真の原因（真因）を客観的かつ網羅的に把握するための「【ITプロジェクト版】失敗原因マンダラ図」を、カスタマイズ容易な**データ分離型Webアセット**として構築したディレクトリです。

## 1. ディレクトリ構成（データとViewerの分離）

```text
05_Projects/it-failure-mandala/
├── index.md                 # OKF Project 定義
├── TODOs/
│   └── TODO.md              # プロジェクトタスク管理
├── index.html               # エントリポイント（ローカルでそのままブラウザ表示可能）
├── data/
│   └── mandala_data.js      # 【データ層】階層構造・用語定義・具体例・再発防止策の定義データ
├── viewer/
│   ├── app.js               # 【表示層】SVGマンダラ自動レイアウト・一覧辞書・AAR振り返りシート機能
│   └── styles.css           # 【表示層】テーマ（Dark / Light）・レイアウトスタイル
└── README.md                # 本ドキュメント
```

* **ホスティングURL**: [https://sukehisa.github.io/it-failure-mandala/](https://sukehisa.github.io/it-failure-mandala/)
* **`file://` プロトコル対応**: ローカルWebサーバを立てなくても、`index.html` をそのままブラウザで開くだけで動作するよう、データを `data/mandala_data.js` (`window.MANDALA_DATA`) として分離しています。
* **Viewerとの完全分離**: `viewer/app.js` 側には固定の項目名や座標をハードコードしておらず、`data/mandala_data.js` の配列構造から放射状のSVGマンダラ図・用語定義テーブル・振り返りワークシートを動的に生成します。

## 2. 収録データと出典について

以下の2つの資料を統合し、**4大領域 × 第1階層（10分類）× 第2階層（全54項目）** のすべての階層構造と用語解説・具体例・再発防止策を収録しています。

1. **SAAJ（日本システム監査人協会）近畿支部 第152回定例研究会 発表資料（2015年5月15日 / 松井秀雄氏・関西IBMユーザー研究会）**
   * https://www.saajk.org/wp/wp-content/uploads/saaj20150515.pdf
   * スライド p.43〜50 に記載されている全49項目の第1階層解説・第2階層用語定義・具体例を網羅。
   * スライド p.56〜66 の「マンダラ図を使用した分析の流れ（Step1〜Step5）」および p.90〜92 の「AAR（After Action Review）手法」をワークシート機能として実装。
2. **失敗学会 / 佐伯徹『DX失敗学 なぜ成果を生まないのか』等の54項目版マンダラ図（ご提示の画像）**
   * 49項目版から拡張された5項目（`想像力不足`、`システム使用方法の変化`、`年齢（高齢化）`、`組織文化の不良`、`安全意識の不良`）を含む全54項目を完全収録。
   * Viewer上部のフィルタで「全54項目（統合版）」「SAAJ 2015発表原典 (49項目)」「54項目拡張での追加分 (5項目)」をワンクリックで切り替えられます。

## 3. カスタマイズ方法

### 方法A: `data/mandala_data.js` を直接テキストエディタで編集する（推奨）

`data/mandala_data.js` 内の `categories` 配列にある各カテゴリの `items` にオブジェクトを追加・編集するだけで、マンダラ図の枝と一覧表が自動更新されます。

```javascript
{
  id: "custom_item_id",           // 一意のID
  label: "AIコーディング検証不足", // マンダラ図のノードに表示される名称
  definition: "生成AIが出力したコードの境界条件やセキュリティリスクを十分に検証せず採用してしまうこと。",
  examples: [
    "プロンプトの前提漏れによりエッジケースでデータ不整合が発生する。"
  ],
  countermeasures: [
    "AI生成コードに対する不変条件（Property-based testing）と設計レビューの徹底"
  ],
  sourceEdition: "custom"
}
```

* 第1階層カテゴリ自体の配置角度を変えたい場合は、各カテゴリの `angle`（度数法: `0`=右, `90`=下, `180`=左, `270`=上）を変更すると、放射状の配置方向が自動で再計算されます。

### 方法B: Viewer画面上からGUI追加・JSON編集して書き出す

1. 右上の **「＋ 項目追加」** ボタン、または各項目を選択した際の **「編集」** ボタンからGUI上で項目を追加・変更できます（変更内容はブラウザの `localStorage` に自動保存されます）。
2. **「⚙️ データ定義・編集」** タブを開き、**「💾 mandala_data.js を保存」** ボタンを押すと、編集後の最新データを `mandala_data.js` ファイルとしてダウンロードし、`data/mandala_data.js` にそのまま上書き保存できます。
